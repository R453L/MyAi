# AI News → Telegram Thread-Prep Bot

## এই বট কী করে
- প্রতি ৪ ঘণ্টায় (দিনে ৬ বার) অটোমেটিক রান হয়
- একাধিক ফ্রি সোর্স (TechCrunch AI, VentureBeat AI, MIT Tech Review, Google News RSS,
  Hacker News, arXiv) থেকে AI নিউজ ঘুরে দেখে
- আগে পোস্ট করা লিংকগুলোর সাথে মিলিয়ে ডুপ্লিকেট বাদ দেয় (`state/posted.json`,
  সর্বোচ্চ ৪২টা এন্ট্রি, নতুন ঢুকলে সবচেয়ে পুরনোটা বাদ যায়)
- OpenRouter-এর ফ্রি মডেল দিয়ে হুক + থ্রেড + (দরকার হলে) ইমেজ প্রম্পট বানায়
- Telegram বট দিয়ে তোমার প্রাইভেট চ্যানেলে পাঠায়, সাথে সোর্স লিংকও থাকে যাতে
  পোস্ট করার আগে নিজে চেক করে নিতে পারো

## ফাইল স্ট্রাকচার
```
.github/workflows/ai-news-bot.yml   -> শিডিউল + রান কনফিগ
fetch_and_post.py                    -> মূল স্ক্রিপ্ট
requirements.txt                     -> পাইথন ডিপেন্ডেন্সি
state/posted.json                    -> ডুপ্লিকেট-চেক ক্যাশ (খালি থেকে শুরু)
```

## সেটআপ ধাপে ধাপে

1. GitHub-এ একটা নতুন রিপোজিটরি বানাও (public বা private দুটোই চলবে)।
2. এই ৪টা ফাইল/ফোল্ডার সেই রিপোতে আপলোড করো, ফোল্ডার স্ট্রাকচার ঠিক রেখে।
3. রিপোর **Settings → Secrets and variables → Actions** এ গিয়ে নিচের Secrets যোগ করো:
   - `OPENROUTER_API_KEY` — openrouter.ai থেকে ফ্রি অ্যাকাউন্ট বানিয়ে API key নাও
   - `OPENROUTER_MODEL` — যেমন `meta-llama/llama-3.1-8b-instruct:free` (openrouter.ai/models
     পেজে গিয়ে ":free" ট্যাগ দেওয়া মডেলগুলো দেখে নিও, লিস্ট মাঝে মাঝে বদলায়)
   - `TELEGRAM_BOT_TOKEN` — Telegram-এ `@BotFather` কে মেসেজ দিয়ে `/newbot` করে বট বানালে টোকেন পাবে
   - `TELEGRAM_CHAT_ID` — তোমার প্রাইভেট চ্যানেলে বটকে অ্যাডমিন হিসেবে যোগ করার পর
     চ্যানেলের numeric ID বের করতে হবে (এটা বের করার পদ্ধতি আলাদাভাবে ধাপে ধাপে দেখিয়ে দিতে পারি)
4. **Actions** ট্যাবে গিয়ে workflow enable করো (নতুন রিপোতে প্রথমবার enable করতে হয়)।
5. টেস্ট করতে **Actions → AI News Thread Bot → Run workflow** বাটনে ক্লিক করে ম্যানুয়ালি
   একবার রান করে দেখো — Telegram চ্যানেলে মেসেজ আসছে কিনা চেক করো।
6. সব ঠিক থাকলে এমনিতেই প্রতি ৪ ঘণ্টায় অটো-রান হতে থাকবে।

## নোট
- এখানে ইমেজ জেনারেশন নেই — শুধু ইমেজ প্রম্পট তৈরি হয়, বাকিটা তুমি ম্যানুয়ালি
  Nano Banana দিয়ে করবে।
- OpenRouter ফ্রি মডেল মাঝে মাঝে বদলায়/ডিপ্রিকেটেড হয় — মডেল কল ফেইল করলে
  `OPENROUTER_MODEL` Secret আপডেট করে নতুন ফ্রি মডেলের নাম বসিয়ে দিলেই হবে।
- সব সোর্স ফ্রি এবং কোনো পেইড API নেই — শুধু X-এর Blue subscription তোমার নিজের
  আলাদা খরচ।
